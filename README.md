# Web Profiler / Data Aggregator

Инструмент для сбора данных посетителей веб-ресурса (веб-страницы).

## Функционал
Скрипт, встроенный в страницу, автоматически собирает доступную информацию о клиенте при каждом визите. Данные используются исключительно для внутреннего ознакомления и не распространяются.

**Сбор данных включает:**
- Идентификация клиента (IP, User-Agent).
- Характеристики устройства (разрешение экрана, ОС, процессор).
- Настройки браузера (часовой пояс, язык, плагины).
- Данные о сессии (Referrer, Timestamp).

## Стек технологий
- **Frontend:** JavaScript (Vanilla / React / Vue)
- **Backend:** Python / Node.js (обработка и хранение)
